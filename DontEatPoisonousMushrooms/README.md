# 别吃毒蘑菇 — 摇头识菌答题特效

> 抖音互动特效：屏幕出现蘑菇与题干，玩家摇头选择答案，答对科普、答错警示。

| 项目 | 说明 |
| ---- | ---- |
| 工程目录 | `DontEatPoisonousMushrooms/` |
| 创作工具 | 像塑 PC 端（工程内部标识 `Douyin AR`），官网 effect.douyin.com |
| 工具版本 | 9.1.3（见 `effect.dyehpj` 的 `version` 字段） |
| 脚本语言 | JavaScript（CommonJS，`require('amazingpro.js')`） |
| 特效类型 | 人脸姿态识别互动答题 |
| 菌种数量 | 36 种（9 栽培食用 + 8 野生可食 + 3 条件可食 + 16 剧毒） |

**当前工程状态**：空白模板。`Assets/main.scene` 为空场景，`Graph/graph.json` 仅有默认的 `Start` / `Update` 事件节点，尚无贴图素材。工程预览用的是 `preview_single_shake_head`（摇头素材），交互方式与 [SampleMathProblem](../SampleMathProblem/README.md) 一致，**脚本与摇头判定逻辑可直接复用那份文档的第三、四章**。

## 一、玩法与素材分工

### 1.1 玩法方向（可拆成多个特效）

同一套蘑菇素材可以支撑多个玩法。**素材出一次，多个特效共用**——这是拆项目的前提。

| 顺序 | 玩法 | 交互 | 判定 | 状态 |
| ---- | ---- | ---- | ---- | ---- |
| **1️⃣** | **蘑菇汤**（下锅接菌） | 蘑菇从上方掉落，把毒蘑菇拨开 / 躲开，可食用的接进锅里 | 结算时看锅里：全安全 → 成功出锅；混进毒菇 → 中毒演出 | 🔜 **下一个做这个** |
| **2️⃣** | **采蘑菇的小姑娘** | 待设计 | 待设计 | 🔲 排队中 |
| — | 摇头二选一 | 屏幕出现两个蘑菇，摇头选左 / 右 | 选中可食用菌得分，选中毒菇失败 | 本文档现有设计，优先级排在上面两个之后 |

**建议的工程命名**（保持和现有项目一样的英文目录名风格）：

| 玩法 | 工程目录 |
| ---- | ---- |
| 蘑菇汤 | `MushroomSoup` |
| 采蘑菇的小姑娘 | `MushroomPickingGirl` |

**「采蘑菇的小姑娘」备注**：玩法待定。这个题材自带经典儿歌，**BGM 和亲子向定位是现成的**，但注意像塑要求用平台内置免费音效，外部儿歌音源有版权风险 —— 立项时先确认曲库里有没有可用的。

**蘑菇汤的设计备注**：

- 需要掉落物理与节奏控制。工程已带 `EffectSettings/Physics2DSettingsModule.json`，像塑支持 2D 物理，路线可行；
- "去掉毒蘑菇"的交互方式待定 —— 摇头拨开、张嘴吃掉、眨眼消除都可以，需要真机试哪个识别最稳；
- **结算演出是传播点**。"锅里混进一颗毒菇 → 中毒"的失败演出比单纯答错更有梗，适合做成合拍素材；
- 难度曲线可以靠掉落速度和毒菇比例调，比 A 的固定二选一更耐玩。

**建议拆成独立工程，而不是一个工程做多模式**：抖音特效平台上一个特效就是一个玩法，拆开各自提审、各自吃流量，封面和简介也能针对性写。素材目录可以从本项目复制过去。

### 1.2 当前进度

| 环节 | 状态 | 说明 |
| ---- | ---- | ---- |
| 素材规范 | ✅ 本文档已定 | 出图尺寸、提示词、命名、目录 |
| 菌种数据 | ✅ [type.txt](type.txt) | 36 条，即梦批量出图的变量源 |
| 贴图素材 | 🔲 未产出 | 按第三章配置批量生成 |
| 工程搭建 | 🔲 空场景 | 复用 SampleMathProblem 的摇头答题结构 |

**与算术题特效的差异**：算术题的答案是脚本现算的数字，本项目的答案是**预先分好类的贴图**。所以出题逻辑要改成「从菌种库随机抽 N 个 → 按题干类型判定正确项」，而不是随机生成数值。菌种的毒性分类必须在代码里有一份数据表（可由 [type.txt](type.txt) 转成 JS 数组），不能只靠文件名。

## 二、素材尺寸规范

### 产出分层

| 环节 | 规格 |
| ---- | ---- |
| AI 出图原始尺寸 | 1024×1024，1:1 正方形 |
| 工程最终尺寸 | 512×512（4 的倍数，降显存，避免手机卡顿与特效包超限） |
| 格式 | PNG32 透明通道，**禁止 JPG 白底图** |
| 单张体积 | TinyPNG 压缩后 < 200KB |
| 资源包上限 | 全部贴图合计 **< 5MB**，满足抖音特效上传限制 |

### 构图硬性要求

蘑菇主体居中、**单颗**、无地面、无草丛、无多余环境，仅保留菌类本体。

## 四、36 种蘑菇特征库

> **数据源在 [type.txt](type.txt)** —— 那是给即梦变量框直接粘贴的原始单列格式。下表是同一份数据的分类视图，供开发时映射毒性标识用。**改动只改 type.txt，避免两处不同步。**

### 🟢 人工栽培食用菌（9 种，标识 `safe`）

| 菌种 | 识别特征 |
| ---- | ---- |
| 香菇 | 菌盖棕褐色表面有裂纹花纹，菌柄短粗 |
| 白玉菇 | 通体洁白菌柄细长，菌盖小巧圆润 |
| 平菇 | 扇形菌盖丛生，菌柄偏短 |
| 杏鲍菇 | 菌柄粗壮肥大肉质厚实，菌盖小 |
| 金针菇 | 整体细长菌盖迷你，成簇生长 |
| 双孢菇 | 圆润白色菌盖无明显菌环 |
| 草菇 | 幼时蛋形，成熟伞盖灰褐色 |
| 黑木耳 | 黑褐色胶质耳朵状褶皱 |
| 银耳 | 乳白色胶质花瓣状褶皱 |

### 🟢 野生安全食用菌（8 种，标识 `safe`）

| 菌种 | 识别特征 |
| ---- | ---- |
| 鸡枞菌 | 细长菌柄基部相连丛生，伞盖舒展 |
| 青头菌 | 青绿色菌盖，菌肉破损**不**变蓝 |
| 奶浆菌 | 受伤流出乳白色乳汁 |
| 松茸 | 黄褐色鳞片菌盖，粗壮菌柄 |
| 美味牛肝菌 | 肥厚黄褐色菌盖菌管结构，碰伤**不**变蓝 |

| 亚稀褶红菇（火炭菌） | 红色菌盖，菌肉破损变红 | 横纹肌溶解 |
| 黄粉末牛肝菌 | 菌盖黄色粉末，碰伤变黄 | 急性肠胃剧毒 |
| 条盖盔孢伞 | 小型黄褐色，**极似香菇** | 肝毒性剧毒 |

## 五、十种画风后缀表

| # | 画风 | 替换后缀文本 |
| ---- | ---- | ---- |
| 1 | 扁平科普插画（**主力工程用**） | 扁平科普图鉴风，粗黑轮廓，高饱和配色，科普识别插画 |
| 2 | 写实水彩手绘 | 写实水彩手绘，柔和色彩晕染，自然写实纹理 |
| 3 | Q 版卡通（儿童版） | Q 版圆润卡通，圆角造型，可爱萌化，儿童科普向 |
| 4 | 铅笔线稿素描 | 铅笔单线线稿，黑白轮廓素描，无填充色 |
| 5 | 8Bit 像素风 | 8bit 像素游戏风，像素硬边缘，复古游戏素材 |
| 6 | 复古植物版画 | 复古植物版画，旧纸张印刷纹理，雕刻线条 |
| 7 | 黏土 3D 盲盒风 | 黏土 3D 盲盒质感，哑光软质粘土渲染 |
| 8 | 极简矢量图标 | 极简矢量图标，大色块扁平化图标 |
| 9 | 微距写实摄影 | 微距写实摄影，自然光实拍质感，高清菌类纹理 |
| 10 | 马克笔涂鸦风 | 马克笔手绘涂鸦，粗笔触高对比撞色 |

> ⚠️ 画风 4（线稿）和 8（矢量图标）会丢失颜色信息。而「变蓝」「变红」「橘色乳汁」这类**颜色本身就是识别特征**，用这两种画风时毒性辨识题会失去依据 —— 仅建议用于纯造型辨识的题目。

## 六、后期处理与命名规范

### 后期步骤

1. `remove.bg` 一键去除背景
2. 批量裁剪为 512×512
3. TinyPNG 压缩

### 命名规则

```
mushroom_<菌种拼音>_<风格序号>_<毒性标识>.png
```

| 毒性标识 | 含义 | 对应分类 |
| ---- | ---- | ---- |
| `safe` | 常规可食用 | 人工栽培 + 野生安全（共 17 种） |
| `conditional` | 条件食用 | 见手青类、墨汁鬼伞（共 3 种） |
| `deadly` | 剧毒 | 16 种 |

示例：

```
mushroom_xianggu_01_safe.png
mushroom_jianshouqing_01_conditional.png
mushroom_baidusan_01_deadly.png
```

> 注意标识只有 3 种，而第四章分了 4 组 —— **`safe` 同时覆盖「人工栽培」和「野生安全」**。如果题干要区分「菜市场买的」和「野外捡的」，光靠文件名不够，得在代码的数据表里另加字段。

## 八、配套文案

### 答对弹窗（绿色）

| 菌种 | 文案 |
| ---- | ---- |
| 香菇 | 家常食用菌，爆炒、煲汤均可正常食用 |
| 白玉菇 | 超市常见菌菇，火锅清炒适配 |
| 鸡枞菌 | 云南名贵野生菌，味道鲜甜可放心食用 |
| 青头菌 | 安全野生菌，充分炒制即可食用 |
| 见手青 | 本菌**必须长时间高温烹煮**，禁止凉拌、生食 |

### 答错警示弹窗（红色）

| 菌种 | 文案 |
| ---- | ---- |
| 白毒伞 | 致命毒蘑菇，50 克即可造成急性肝衰竭，请勿采摘食用 |
| 毒蝇伞 | 神经毒性蘑菇，误食会产生幻觉、呕吐 |
| 亚稀褶红菇 | 剧毒火炭菌，误食引发肌肉溶解，危及生命 |
| 盔孢伞 | 外形酷似香菇，剧毒肝损，野外切勿凭经验采菌 |

> 文案目前只覆盖 9 种菌，剩下 27 种在做题库时需要补齐 —— 否则答对 / 答错弹窗会有大量菌种无话可说。

### 顶部题干（随机）

- 找出可以放心吃的蘑菇
- 选出属于见手青的菌类
- 识别剧毒野生蘑菇
- 菜市场可食用蘑菇辨别
- 野外捡菌避雷，找出毒蘑菇

> ⚠️ **免责声明**：本特效为**娱乐科普**用途，不构成任何野外采食建议。野生菌辨识极易出错，多种剧毒菌与食用菌外观高度相似 —— 发布时建议在特效内或简介中带上「请勿依据本特效采食野生菌」的提示。
